Folder tahun untuk kartu publikasi yang **PUB ID-nya diberikan pada 2026** (tahun mengikuti tahun Issue Publication dibuka, bukan tahun terbit). Satu file per publikasi.

## Isi folder

| File | Isi |
|---|---|
| `README.md` | halaman ini: daftar kartu tahun 2026 |
| `PUB-2026-NNN-slug.md` | satu kartu per publikasi, dibuat dari [`_template/publication-card.md`](../_template/publication-card.md); slug kebab-case, English, ≤5 kata |

Artefak (`ART-*`) tidak memiliki kartu terpisah di folder tahun; ia dicatat pada tabel artefak di [PUBLICATIONS.md](../PUBLICATIONS.md) dan pada kartu publikasi yang menyertainya (bila ada).

## Petunjuk membuat kartu

1. Pastikan Issue **Publication** sudah dibuka dan `PUB-2026-NNN` sudah diberikan pengelola (lihat counter di [PUBLICATIONS.md](../PUBLICATIONS.md)).
2. Salin `_template/publication-card.md` menjadi `2026/PUB-2026-NNN-slug.md`; isi semua field — tidak ada field kosong; pakai "none" bila memang tidak ada (mis. Artifact).
3. Tambahkan baris di tabel indeks [PUBLICATIONS.md](../PUBLICATIONS.md) dan di tabel *Daftar kartu 2026* di atas.
4. Buka PR; reviewer memeriksa: Research ID valid, venue ada di venue registry, AI Usage Statement ada, checklist integritas ditandatangani sebelum status *Submitted*.
5. Perbarui kartu dan indeks ≤7 hari setiap kali status berubah; setelah *Published*, lengkapi DOI dan sitasi BibTeX.

Jangan menyimpan PDF penerbit di folder ini ([Publications README](../README.md) §2).
